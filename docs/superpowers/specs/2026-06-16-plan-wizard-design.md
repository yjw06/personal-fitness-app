# 맞춤 마스터플랜 생성기 (PlanWizard) — 설계 문서

작성일: 2026-06-16

## 배경 / 문제

피트니스 앱을 일반 사용자에게 공유하려는데, AI 코치의 핵심인 **마스터플랜**(시스템 프롬프트 역할)을 일반인이 직접 작성하기 어렵다. 마스터플랜이 비어 있으면 AI 코치 품질이 크게 떨어진다.

마스터플랜은 단일 텍스트가 아니라 **4개의 분리된 필드**다 (`memoryStore`):

| 필드 | 의미 |
|---|---|
| `profile` | 나이·키·체중·목표 등 사용자 프로필 |
| `workoutPlan` | 주간 운동 루틴/분할법 (산문 가이드) |
| `mealPlan` | 목표 칼로리/식단 방향 (산문 가이드) |
| `coachPersona` | 코치 톤·말투 |

따라서 이 기능의 목표는 "좋은 프롬프트 1개 만들기"가 아니라 **이 4칸을 잘 채워주기**다.

## 목표

몇 가지 질문에 답하면 위 4칸이 자동으로 채워지는 위저드를 제공한다. 외부 AI 복붙·파싱 경로를 **권장 경로**로 두고, Gemini API 자동 경로도 선택지로 제공한다.

## 비목표 (YAGNI)

- 일일 운동/식단 CSV 생성은 기존 `promptBuilder.js` 흐름이 담당. 본 기능은 **마스터플랜(산문 가이드)** 생성까지만.
- 다국어/단위(lb, inch) 지원 — 한국어·미터법 고정.
- 목표 다중 선택 — 단일 선택으로 제한(프롬프트 일관성).

## 결정 사항 (확정)

1. **생성 대상**: 4칸 전부 생성. 단, `profile`의 사실값(나이·키·체중 등)은 AI 추측이 아니라 **사용자 입력값을 그대로** 사용.
2. **경로**: 복붙·파싱 + Gemini 자동 **둘 다 제공**, 단 복붙·파싱이 **"권장"으로 강조** 표시.
3. **목표**: 단일 선택.
4. **파싱 형식**: 구분자 블록 (JSON/CSV 아님).

## 질문 세트 (5스텝)

모든 질문은 4칸 중 하나를 채우기 위해 존재한다. 대부분 **탭 선택(칩)**, 자유 입력은 목표·제약 등 꼭 필요한 곳만. 필수 11개(숫자 3 + 칩 8) + 선택 3개.

### STEP 1 · 나에 대해 → `profile`
| 질문 | 입력 | 필수 |
|---|---|---|
| 성별 | 칩: 남 / 여 / 비공개 | ✓ |
| 나이 | 숫자 | ✓ |
| 키 (cm) | 숫자 | ✓ |
| 현재 체중 (kg) | 숫자 | ✓ |
| 운동 경력 | 칩: 입문(~6개월) / 초급(~2년) / 중급(~5년) / 고급(5년+) | ✓ |

### STEP 2 · 목표 → 운동·식단 방향 결정
| 질문 | 입력 | 필수 |
|---|---|---|
| 가장 큰 목표 (1개) | 칩: 근육 키우기 / 체지방 감량 / 근력 향상 / 체력·건강 / 체형 교정 | ✓ |
| 구체적 목표·시한 | 자유: "3개월 5kg 감량", "벤치 100kg" | 선택 |

### STEP 3 · 운동 환경 → `workoutPlan`
| 질문 | 입력 | 필수 |
|---|---|---|
| 주당 운동 횟수 | 칩: 2 / 3 / 4 / 5 / 6+ | ✓ |
| 1회 운동 시간 | 칩: 30 / 45 / 60 / 90분+ | ✓ |
| 장소·장비 | 칩: 헬스장 / 홈(덤벨·밴드) / 맨몸만 | ✓ |
| 부상·기피 부위 | 자유: "허리 디스크", "무릎 안 좋음" | 선택 |

### STEP 4 · 식단 → `mealPlan`
| 질문 | 입력 | 필수 |
|---|---|---|
| 식단 관리 수준 | 칩: 칼로리·매크로 엄격 / 대략 가이드만 / **식단 빼기** | ✓ |
| 하루 식사 패턴 | 칩: 3끼 / 3끼+간식 / 2끼(간헐단식) / 자유 | ✓ |
| 식이 제약·알레르기·선호 | 자유: "유당불내증", "채식", "닭가슴살 질림" | 선택 |

> **"식단 빼기" 분기**: 선택 시 STEP 4의 나머지 질문 생략, 프롬프트에서 `===MEAL===` 요청 제외, 파싱·저장에서 `mealPlan` 미변경.

### STEP 5 · 코치 스타일 → `coachPersona`
| 질문 | 입력 | 필수 |
|---|---|---|
| 코치 말투 | 칩: 친근한 형·누나 / 엄격한 PT쌤 / 데이터 중심 담백 / 유쾌한 동기부여 | ✓ |

## 파싱 형식 — 구분자 블록

외부 AI(또는 Gemini)가 다음 고정 마커로 4블록을 감싸 답하도록 프롬프트에서 지시:

```
===PROFILE===
(프로필 내용)
===WORKOUT===
(운동 가이드)
===MEAL===
(식단 가이드)
===PERSONA===
(코치 페르소나)
===END===
```

- 파싱: 마커 기준 split (정규식). 블록별 trim 후 해당 필드에 매핑.
- "식단 빼기" 시 프롬프트에서 `===MEAL===` 섹션 요청 제외, 파싱에서도 `mealPlan` 건너뜀.
- **폴백**: 마커가 하나도 안 잡히면 "응답을 다시 복사해 주세요" 안내 + 붙여넣은 원문을 4칸에 수동 배치할 수 있는 화면 제공.

## 진입점 (2곳)

1. **빈 상태 트리거** — `CoachPage.jsx:488`의 *"메모리 없음 — 설정에서 마스터플랜 등록"* 자리를, 4칸이 모두 비었을 때 **"✨ AI로 내 맞춤 플랜 만들기"** CTA 버튼으로 교체.
2. **설정창** — `SettingsModal` 마스터플랜 섹션 상단에 생성기를 여는 버튼 추가(언제든 재생성).

## 위저드 흐름

```
[5스텝 질문]
   ↓
[경로 선택: 복붙(권장) / Gemini 자동(API 키 있을 때만 노출)]
   ├─ 복붙:  프롬프트 생성 → 복사 버튼 + 외부 AI 링크 → 응답 붙여넣기 → "분석해서 채우기"
   └─ Gemini: "바로 생성" → API 호출 → 동일 파싱
        ↓
[미리보기·수정 화면] 파싱된 4칸을 표시·편집 (바로 저장 X)
   ↓
[저장] memoryStore.save(uid, { profile, workoutPlan, mealPlan, coachPersona })
```

- **미리보기·수정 단계 필수**: 파싱 결과를 바로 저장하지 않고 사용자가 확인·편집. 파싱 실패 안전망 + 신뢰감.
- Gemini 자동 경로는 `memory.apiKey`가 있을 때만 노출. 호출 실패 시 복붙 경로로 폴백 유도.

## 컴포넌트 / 아키텍처

| 단위 | 책임 | 의존 |
|---|---|---|
| `PlanWizard` (신규 컴포넌트, 독립 모달) | 5스텝 질문 UI, 경로 선택, 미리보기·저장 오케스트레이션 | `promptBuilder`, `memoryStore`, `aiCoach`(Gemini 경로) |
| `promptBuilder.js` (기존, 함수 추가) | 위저드 답변 → 외부 AI 프롬프트 텍스트 생성, 응답 → 4필드 파싱 | 없음 (순수 함수) |
| `CoachPage` / `SettingsModal` (기존, 수정) | 진입점 버튼 추가, `PlanWizard` 마운트 | `PlanWizard` |

- `PlanWizard`는 두 진입점에서 재사용하도록 독립 모달로 분리.
- 프롬프트 생성·파싱은 순수 함수로 `promptBuilder.js`에 추가 → 단위 테스트 용이.

### 새 순수 함수 (promptBuilder.js)
- `buildPlanWizardPrompt(answers)` → 외부 AI에 붙여넣을 프롬프트 문자열. "식단 빼기" 분기 반영.
- `parsePlanWizardResponse(text, { includeMeal })` → `{ profile, workoutPlan, mealPlan, coachPersona }` 또는 파싱 실패 표시.

## 에러 처리

| 상황 | 처리 |
|---|---|
| 파싱 마커 없음 | 안내 + 수동 배치 폴백 화면 |
| 일부 블록만 누락 | 있는 블록만 채우고 누락 블록은 미리보기에서 빈칸 표시 |
| Gemini 호출 실패/혼잡 | 토스트 안내 + 복붙 경로 사용 유도 |
| 필수 질문 미응답 | 다음 스텝 진행 비활성화 |

## 테스트

- `buildPlanWizardPrompt`: 식단 포함/제외, 선택 항목 유무에 따른 출력 검증.
- `parsePlanWizardResponse`: 정상 4블록, 식단 제외, 마커 누락(폴백), 일부 블록 누락 케이스.
